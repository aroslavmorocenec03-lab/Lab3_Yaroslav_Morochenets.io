# Фотоальбом — лабораторна робота № 3

**Ярослав Мороченець.** Відкрийте `index.html` у браузері. Альбом містить локальні фото Землі, Місяця та Юпітера; натискання відкриває повний знімок. Адаптивний макет підтримує вузькі екрани.

## Виконані дії Git

Клоновано навчальний шаблон, створено альбом, додано `.gitignore` з правилом `*.txt`, виконано коміт `My album`. Далі створено коміт `Bad feature` з файлом `bad_feature.js` і скасовано його через `git revert`. Обидва коміти залишилися в історії; у поточній версії `bad_feature.js` відсутній. Origin змінено на цей власний репозиторій.

Шаблон з методички `FCIT-SoftwareEngineeringBasics/Lab3.io` повернув 404, тому використано [MDN beginner-html-site-styled](https://github.com/mdn/beginner-html-site-styled). Початкову історію та ліцензію CC0 збережено.
